About Xrypton

Xrypton is a powerful, feature-rich Discord bot built with discord.py. It offers a wide range of commands across multiple categories including moderation, information, fun, configuration, automation, engagement, anti-nuke, and developer tools.

The bot uses a modern hybrid command system supporting both prefix and slash commands, with a clean and intuitive interface for server management and entertainment.
