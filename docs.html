Documentation

Everything you need to get Hollow invited, configured, and running smoothly in your server.

Getting started

  1. Invite Hollow. Hit Add to Discord, pick your server, and approve the requested permissions.
  2. Grant permissions. Make sure Hollow's role sits above the roles it manages, with Manage Messages, Moderate Members and Manage Roles enabled for full functionality.
  3. Configure your modules. Set a welcome channel, enable auto-role, and drop reaction roles wherever members self-assign.
  4. Explore commands. Browse the full list on the commands page — every entry shows its arguments and required permissions.
Something not responding? Join the support server and open a ticket — most setup issues come from role hierarchy.

Core concepts

Commands

Every Hollow feature is exposed as a slash command. Type / in Discord to see the live list, including inline argument hints. The commands page mirrors this data from Hollow's public API.

Permissions

Moderation commands check Discord's native permissions first, then Hollow's own case log. Members with Administrator bypass all checks; everyone else needs the permission listed on the command card.

Modules

Leveling, welcome messages, automations, and integrations can each be toggled per server. Nothing runs unless you enable it.

Moderation

  • /ban, /kick, /timeout — standard actions with optional reasons and DMs.
  • /warn — records warnings against a member so patterns are visible across your mod team.
  • /purge — bulk delete up to 100 messages, optionally filtered by member or bot.

Every action is written to the case log with the moderator, target, and reason attached.

Leveling

Members earn XP for participating. Use /rank to show progress, /leaderboard to see the server's top members, and /setlevel to adjust a member manually (requires Manage Server).

Automations

  • /welcome — greeting message with {user} and {server} placeholders.
  • /autorole — assign a role the moment someone joins.
  • /reactionrole — turn any message into a self-assign role menu.
  • /customcommand — build your own trigger-and-response commands.

Integrations

Link the platforms your community already uses: Last.fm, Spotify, X, TikTok, GitHub, Valorant, Minecraft, and Roblox — all queried natively in chat. See the integration showcase for what each one can do.

Getting help

Join the support server for setup help, bug reports, and release notes. For account or data requests, check the privacy policy.
